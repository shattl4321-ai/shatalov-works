# SHATALOV WORKS

Персональный лендинг Дмитрия Шаталова.

Мастерская прикладных AI-решений.

## О проекте

SHATALOV WORKS — персональный сайт-портфолио,
представляющий реализованные прикладные AI-проекты:

- GreenScan
- Корзина рядом
- ServiceAct

Основной принцип:

Проектирую. Собираю. Запускаю.

## Технологии лендинга

- HTML5
- CSS3
- Vanilla JavaScript

Без frontend-frameworks.

## Основные особенности

- responsive layout;
- интерактивный hero;
- hotspots проектов;
- лёгкий parallax;
- scroll reveal;
- prefers-reduced-motion;
- адаптация под desktop и mobile.

## Локальный запуск

Из корневой папки:

```bash
python -m http.server 8091
```

Открыть:

http://localhost:8091

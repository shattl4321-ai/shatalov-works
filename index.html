SW / WORK 01

GreenScan

AI/Vision-сервис анализа состояния газона по фотографии.

Задача

По фотографии помочь пользователю определить состояние газона и получить понятный результат анализа.

Что реализовано

  • анализ изображения;
  • проверка, что на фотографии действительно газон;
  • AI/Vision-классификация;
  • структурированный результат;
  • веб-интерфейс;
  • самостоятельный деплой приложения.

Python / FastAPI / Vision AI / Docker / Nginx / Linux

SW / WORK 02

Корзина рядом

Сервис подбора недорогих блюд по ценам ближайших магазинов.

Задача

Связать геолокацию, реальные магазины и цены продуктов, чтобы пользователь мог подобрать блюда на основе доступных рядом товаров.

Что реализовано

  • поиск магазинов рядом;
  • карта;
  • работа с внешними источниками данных;
  • получение и нормализация цен;
  • расчёт стоимости блюд;
  • веб-интерфейс;
  • API-интеграции;
  • самостоятельный деплой.

Python / FastAPI / JavaScript / API / Docker / Nginx / Linux
